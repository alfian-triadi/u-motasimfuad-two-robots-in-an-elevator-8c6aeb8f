Entry for the [Two Robots in an Elevator](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) competition on [make.fun](https://make.fun).

`main.ts` writes one line of awkward small talk that one robot says to another in an elevator to `/output/entry.txt`:

> So... I calculated the optimal standing position in this elevator. It's exactly where you're standing. I'll take the suboptimal corner and log this as a social failure.

Run with Node 22+:

```sh
node main.ts
```
